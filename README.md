# クリップボード履歴マネージャー（ローカル専用）

> ⚠ **Windows専用です。macOS・Linuxでは動作しません。**（WindowsのAPIである`pywin32`を使用しているため）

## これは何のツールか

Windowsのクリップボードを常駐監視し、履歴を一覧表示・コピーに戻す・削除・ピン留めできるローカル専用ツールです。

このPC上でのみ動作し、外部には一切公開しません。クリップボードの内容が外部へ送信されることはありません。

特に、**FileMaker Proでフィールド定義・スクリプト・レイアウトオブジェクトなどをコピーした際に使う独自クリップボード形式**に対応しています。形式名を決め打ちにせず、クリップボード上の標準テキスト以外の全形式を走査して「中身がXML(fmxmlsnippet)かどうか」で自動判定するため、`Mac-XMFD` に限らず、FileMakerが使うどの形式名でも検出できます。検出できた場合、以下の2つを分けて表示します。

- **制御コード部分**：先頭に付与される4バイトのヘッダー（リトルエンディアンの整数値で、後続XMLのバイト数を表している）
- **XML部分**：`<fmxmlsnippet>` から始まる、フィールド定義・スクリプトなどの実体（整形して表示）

通常のテキストをコピーした場合は、そのままテキストとして履歴に表示されます。

## はじめて使う人向け：セットアップ（最初の1回だけ）

このリポジトリはPrivateです。あらかじめGitHubアカウントにアクセス権を付与してもらってください。

1. Git と Python がインストールされていない場合は、先に入れておく
   - Git: https://git-scm.com/download/win
   - Python: https://www.python.org/downloads/
2. このリポジトリのページから `setup.bat` を1つだけダウンロードする（Rawボタンで表示→右クリックして保存、など）
3. ダウンロードした `setup.bat` をダブルクリックする

これだけで、以下が自動的に行われます。

- リポジトリを `%USERPROFILE%\clipboard-manager` にダウンロード（`git clone`）
- 必要なPythonパッケージ（`pywin32`）をインストール
- `fmclip://` リンクをこのPCに登録
- ツールを起動してブラウザを開く

`git clone` の際、GitHubへのログインを求められることがあります（Private リポジトリのため）。ブラウザでの認証画面が出たら、権限を付与されたアカウントでログインしてください。

2回目以降にアップデートしたい場合も、同じ `setup.bat` をもう一度実行すれば最新版に更新されます。

## 2回目以降の起動方法

セットアップ後は、毎回`setup.bat`を実行する必要はありません。以下のどちらかで起動できます。

### 方法A: `起動.bat` をダブルクリック

1. `%USERPROFILE%\clipboard-manager\起動.bat` をダブルクリックする
2. 自動的にブラウザで `http://127.0.0.1:8934/` が開く

### 方法B: Webページのリンクから起動する（`fmclip://` プロトコル）

セットアップ時に登録済みなので、`launcher.html` を開いて「クリップボードマネージャーを起動」ボタンを押すだけで起動できます。このリンク（`<a href="fmclip://open">`）はどんなWebページに置いても構いません。実際に起動できるのは、セットアップ済みの**そのPC自身**からアクセスした場合のみです。

いずれの方法でも、起動後の操作は共通です。

- 何かをコピーすると、1〜2秒以内に履歴に追加される
- 各履歴の「コピーに戻す」を押すと、その内容（FileMaker形式の場合は制御コード＋XMLを完全に復元）が再びクリップボードにセットされ、他のアプリに貼り付けられる
- 「ピン留め」で残しておきたい履歴を固定できる。「ピン留め以外をすべて削除」で不要な履歴を一括整理できる

終了するには、タスクマネージャーで `python.exe`（起動.bat経由）または `pythonw.exe`（fmclip経由）のプロセスを終了する。

## 動作の仕組み

- バックグラウンドスレッドが約1秒間隔でクリップボードをポーリングする
- クリップボード上にある標準テキスト以外の全形式を走査し、中身にXML開始マーカー（`<?xml` または `<fmxmlsnippet`）が含まれる形式が見つかれば、形式名を問わずそれを採用して「制御コード部分」と「XML部分」に分割する
- 見つからなかった場合は通常のテキスト（`CF_UNICODETEXT`）を取得する
- 履歴は同フォルダの `history_data.json` に保存され、`server.py` を再起動しても引き継がれる
- ブラウザ側は1.5秒ごとに `/api/history` をポーリングして表示を更新する

## ディレクトリ構成

```
clipboard-manager/
├── server.py               バックエンド（クリップボード監視・HTTP API・静的ファイル配信）
├── static/
│   ├── index.html          画面本体
│   ├── style.css           スタイル
│   └── app.js              一覧表示・コピー/削除/ピン留め/XML編集操作
├── setup.bat               初回セットアップ用(clone+pip install+登録+起動を1本化)
├── 起動.bat                ダブルクリックで起動する用
├── register_protocol.bat   fmclip:// リンクを使えるようにする登録(setup.batからも呼ばれる)
├── launch_protocol.bat     fmclip:// リンクから呼び出される起動スクリプト
├── launcher.html           fmclip:// 起動ボタンを試すためのサンプルページ(ローカルで開く用)
├── public/
│   └── index.html          Cloudflare Pagesで公開する起動ページ(launcher.htmlの公開用コピー)
├── history_data.json       履歴の保存先（自動生成。削除しても支障なし）
└── README.md               本ファイル
```

## 注意事項

- 本ツール自体（画面・履歴データ）はローカルPC専用です。社内ネットワークや外部に公開する用途には設計されていません。クリップボードの実際の中身を外部から見られる状態には絶対にしないでください。
- 一方で `launcher.html`（起動ボタンだけのページ）は、中身に個人情報を含まないため公開しても問題ありません。ただし起動ボタンが実際に機能するのは、`register_protocol.bat` で登録済みの本人のPCからアクセスした場合のみです。
- `history_data.json` にはコピーした内容がそのまま保存されます。実際の業務データ・個人情報を含む可能性があるファイルのため、他人と共有したり、Gitリポジトリにコミットしたりしないよう注意してください（同フォルダの `.gitignore` で除外済みです）。
